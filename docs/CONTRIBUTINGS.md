# Contributing to memoria

## Commit Messages

Format:
type: short of description why

## Types

- feat : new feature
- fix : bug fix
- docs : documentation
- chore : dependencies or maintenance
- refactor : restructure without behaviour change
- test : adding or updating tests

## Examples

feat: start server with validated env config
docs: add phase scope to PHASES.md
chore: install pino-pretty for dev logging
